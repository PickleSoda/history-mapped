# Licence of the History Mapped demo data set

The demo data set is the curated core of History Mapped, an interactive historical atlas: about
36,000 entities, their relationships, the chronicles and the battle maps. Each part keeps the
licence of where it came from:

| Part | Source | Licence |
|---|---|---|
| Facts: names, types, dates, coordinates, relationships, identifiers | [Wikidata](https://www.wikidata.org) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain) |
| Entity summaries taken from an article's lead | [Wikipedia](https://www.wikipedia.org) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); the article is the one linked from the entity's Wikidata item |
| Borders and placed points | [OpenHistoricalMap](https://www.openhistoricalmap.org) | CC0 1.0 unless the feature states another licence; credit "OpenHistoricalMap contributors" |
| Images | Wikimedia Commons | Not included. The data holds links and credits only; each image has its own licence on Commons |
| Everything written for the atlas: chronicle texts, battle-map steps and narration, descriptions, tags, the selection and arrangement of the set | History Mapped | CC0 1.0 (public domain) |

In short: use it for anything. If you republish entity summaries, keep the Wikipedia attribution
and the share-alike terms for those texts.

The data is provided as is, with no warranty. It contains errors; rows marked `needs_review` or
`pipeline_draft` have not been checked by a person.
