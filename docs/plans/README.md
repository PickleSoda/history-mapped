# Plans — Live Product Roadmap & Backlog

The product-level backlog: what we intend to build, per program. Only **in-progress or
not-started** plans live here — fully-executed plans move to [../archive/plans/](../archive/plans/),
so this folder reads as the backlog.

> **Start with [STATUS.md](STATUS.md)** — the verified per-plan execution status
> (✅ executed · 🟡 partial · ⬜ not started), checked against the live codebase.
> Plan checkboxes and headers inside individual plan files are *not* authoritative.

## Conventions

- The OHM program keeps its `ohm-phase-N-*` names; cross-cutting efforts are named by topic.
- Fine-grained engineering tasks not owned by a plan go in [../TODO.md](../TODO.md), not here.
- Dated agent-driven implementation plans (with paired design specs) live in
  [../superpowers/](../superpowers/), not in this folder.
- When a plan fully ships: move it to [../archive/plans/](../archive/plans/) and update
  [STATUS.md](STATUS.md).
